# Python for AI 🤖🐍

This repository documents my journey into learning **Artificial Intelligence using Python**.  
It was created after following a tutorial by Dave Ebbelaar, where I explored how Python is used to build AI-related projects.

---

## 🚀 About the Project

This project is a collection of experiments, notes, and mini-projects that helped me understand the fundamentals of AI with Python.

It covers core concepts such as:
- Python basics for AI
- Data handling and preprocessing
- Simple machine learning ideas
- Practical coding exercises

The goal of this repo is to **learn by building** and gradually improve my understanding of AI systems.

---

## 🧠 What I Learned

Through this project, I learned:

- How Python is used in AI workflows  
- Writing clean and structured Python code  
- Basics of machine learning concepts  
- Working with data and simple models  
- Problem-solving through hands-on coding
